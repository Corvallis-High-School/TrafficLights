# Java Processing-Style Project Starter

Use this repository as a starting point for Java projects that behave like Processing sketches. Fork it to create your own project, then add your sketch code and assets. Begin with these [Instructions](Instructions.md) to get started.

The project requires JDK 25 or newer to build and run. The development container uses JDK 25; rebuild an existing container to apply the updated image. A separate JDK can be used without replacing your system-wide Java installation.
