# Instructions

## Make a Fork of this repository

1. Append your GitHub username to the new Repository name
   - If your username is StudentCHS, the new repository will be processing-starter-web-StudentCHS
2. Make sure to select Corvallis-High-School as the owner of this repository
   - You should have received an invitation to join Corvallis-High-School
   - This way you do not need to add me as a collaborator
   - You will also be able to take advantage of more Codespaces allocations

## PRIMM

1. **Predict**: What will you see? What happens when you click each light? Run: Click all three lights. Were you right?
2. Investigate: Find the code that checks a click on the red light. Why can't you get back to green?
3. Modify: Make yellow and green clickable.
4. Make: Drive on green, slow on yellow, stop on red.
5. Bonus: Wrap the car around the screen.

## Extensions

1. **Timer**: Create a timer which changes the traffic lights on a schedule
2. **Environment**: Change the scene on a day/night schedule
